# Assets

Carpeta para imágenes y evidencias referenciadas desde los archivos Markdown de `/docs` (spec §15.1), por ejemplo capturas de despliegue en Kubernetes (pods, servicios, PVC) o de ejecución de Docker Compose citadas en `docker.md` y `kubernetes.md`.

Los diagramas de arquitectura y modelo de datos están embebidos como bloques Mermaid directamente en `arquitectura-general.md` y `modelo-datos.md`; esta carpeta se usa para evidencia fotográfica que no puede expresarse como diagrama.
